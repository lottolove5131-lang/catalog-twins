Catalog Twins

Two listings, one inventory headache. Find similar descriptions and compare the details before deciding what to keep.

Private by design. Listing text is processed in this browser. The first run downloads an open model and its runtime from Hugging Face and jsDelivr. No account or AI API key is required.
How to read the results

Scores measure text similarity, not the probability that two listings are the same product. Different sizes, quantities or condition can still score highly. Compare both descriptions and shared terms. This tool never merges or deletes a listing. English descriptions work best; keep descriptions short.
